# Student Management System

A beginner-friendly Student Management System built to practice Python, Object-Oriented Programming, HTML, CSS, and JavaScript.

## 📌 Project Overview

This project allows users to enter student details and marks, calculate the total and average, and determine whether the student has passed or failed.

The project is being developed step-by-step while learning frontend and backend development.

## ✨ Features

- Student information input
- Student age validation
- Marks input validation
- Marks validation between 0 and 100
- Total marks calculation
- Average marks calculation
- Pass/Fail result calculation
- Interactive web interface
- JavaScript DOM manipulation
- Python Object-Oriented Programming practice
